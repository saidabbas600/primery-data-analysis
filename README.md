## Primary Data Analysis - Afghan Refugee Crisis
This repository contains the data cleaning, processing, and econometric analysis of primary survey data collected to understand the socio-economic conditions and challenges faced by Afghan refugees. The project focuses on transforming raw field data into actionable insights through rigorous statistical modeling.
## Project Overview
The analysis investigates key indicators such as household income, access to healthcare, education gaps, and labor market integration among refugee populations. By utilizing primary data, this project provides a granular view of the crisis that secondary sources often miss, specifically focusing on the vulnerabilities and resilience of displaced households.

## Econometric Techniques:
1) Data Cleaning: Handling missing values, outliers, and complex survey weights to ensure representativeness.
2) Descriptive Statistics: Comprehensive profiling of demographic characteristics.
3) Regression Analysis: Identifying determinants of economic well-being and social integration.
4) Categorical Data Analysis: Using Probit/Logit models to assess factors affecting access to essential services.
